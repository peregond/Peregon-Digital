# peregon.cc

Статический сайт из четырёх страниц. Без сборки и зависимостей: HTML, один CSS-файл, один JS-файл.

| Адрес | Что это | Файл |
| --- | --- | --- |
| `peregon.cc` | Главная: гуу-блобы, голо-карточки линий, лента работ (стили в `assets/css/home.css`) | `index.html` |
| `peregon.cc/digital` | Визитка компании Peregon Digital | `digital/index.html` |
| `peregon.cc/hire` | Портфолио и резюме для HR | `hire/index.html` |
| `peregon.cc/vibe` | Технические проекты | `vibe/index.html` |

## Идея дизайна

«Перегон» — участок пути между двумя станциями. Сайт устроен как схема линий: у каждого раздела свой цвет
(Digital красный, Hire синий, Vibe жёлтый), круглые «буллеты» линий в навигации, моноширинные подписи как на табло.
Слева на широких экранах идёт «рельс» прокрутки со станциями-разделами страницы.

## Как посмотреть локально

```bash
python3 -m http.server 8000
```

Затем открыть `http://localhost:8000`. Пути к ассетам абсолютные (`/assets/...`), поэтому открывать файлы двойным кликом не получится.

## Как править

- **Тексты.** Английский текст лежит прямо в HTML. Русский перевод лежит в конце каждой страницы в объекте `window.I18N_RU`:
  ключ совпадает с атрибутом `data-i18n` у элемента. Общие строки шапки и подвала находятся в `assets/js/site.js` (`COMMON_RU`).
- **Язык.** По умолчанию берётся язык браузера, выбор запоминается. Ссылку можно зафиксировать: `peregon.cc/hire?lang=en` или `?lang=ru`.
- **Цвета и шрифты.** Токены в начале `assets/css/site.css` (блок `:root`).
- **Видео.** Плитка `<a class="yt" data-yt="ID">` с превью из `assets/img/work/ID.webp`. До клика запросов к YouTube нет.
- **Шапка и подвал** продублированы в каждой странице. При изменении нужно поправить все пять файлов (включая `404.html`).
- **Версии приложений** на `/vibe` подтягиваются из GitHub Releases (`data-release="owner/repo"`), в HTML записано запасное значение.

## Публикация на GitHub Pages

1. Смёрджить ветку в основную.
2. Settings → Pages → Deploy from a branch → корень репозитория.
3. Файл `CNAME` уже содержит `peregon.cc`. У регистратора домена добавить A-записи GitHub Pages
   (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) и включить Enforce HTTPS.

Сайт так же без изменений работает на Cloudflare Pages, Netlify и Vercel.
